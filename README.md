# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date: 27-11-2026

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

* Open New File
* Select Sketch
*  Select Front View
*  Draw a rectangle using a two point rectangle with a measure of base 100mm and height 50mm.
<img width="1195" height="572" alt="Screenshot 2026-11-27 152845" src="https://github.com/user-attachments/assets/07d2667f-5560-471d-9fa1-4740be708b04" />

*  Extrude the rectangle by giving finish sketch then  extrude it with a distance of 30mm.
*  choose the create sketch and select front view Draw the circle in the middle of the rectangle of the diameter 50.
*  Extrude that to with the distance of 20mm.
